This is a repo for an in-course research report about "Gift Detection and Recognition from Images". It was written in Python using VScode as the IDE.
There have been a couple iterations of the dataset up to the current one, though still inadequate for quality investigation, and running it will showcase a Precision-Recall Graph alongside a Confusion Matrix.
Future improvements could be creating and refining a "Gifts" dataset as well as training the models of Yolo and Clip with transfer learning to improve results.

To set up this repo and view the current results, set up a virtual environment in VScode and install the requirements.txt dependencies, then run main.py
